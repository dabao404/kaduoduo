# 更新日志 / Changelog

## 0.1.0

### 中文

- 初始化 Kotlin + Jetpack Compose Android 项目。
- 增加 Room 本地数据模型：银行、信用卡、年费规则、调额记录和权益。
- 增加首页、添加卡片页和详情管理页。
- 支持年费进度展示、调额记录新增、权益新增与核销。

### English

- Initialized the Kotlin + Jetpack Compose Android project.
- Added Room local data models for banks, credit cards, annual fee rules, limit history, and benefits.
- Added the home screen, add card screen, and detail management screen.
- Added annual fee progress display, limit history creation, benefit creation, and benefit redemption.
