# 安全策略 / Security Policy

## 中文

### 报告安全问题

如果你发现安全问题，请不要在公开 Issue 中披露可利用细节。请通过项目维护者在 GitHub 主页公开的联系方式沟通。

### 数据说明

卡多多当前仅使用本地 Room 数据库保存用户输入的信用卡管理信息，不包含远程同步能力。请不要在 Issue 或 PR 中提交真实卡号、账单截图、身份证明、手机号、验证码或其他敏感信息。

## English

### Reporting Security Issues

If you find a security issue, please do not disclose exploitable details in a public Issue. Contact the maintainer through the public contact information on their GitHub profile.

### Data Notes

kaduoduo currently stores user-entered credit card management data only in a local Room database and does not include remote synchronization. Please do not submit real card numbers, billing screenshots, identity documents, phone numbers, verification codes, or other sensitive information in Issues or Pull Requests.
